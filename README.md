## 📘 Description

This repository is created to **practice and understand Reflection in C#**.  
Reflection is a powerful feature in .NET that allows a program to:

- Inspect classes, methods, properties, and fields  
- Access metadata at runtime  
- Dynamically create objects  
- Invoke methods without knowing them at compile time  

Reflection is widely used in **real-world backend development**, frameworks, and tools like:

- Dependency Injection  
- ORM frameworks (Entity Framework)  
- Middleware pipelines  
- Dynamic Proxies  

This repository is organized in a **branch-wise learning structure**.
